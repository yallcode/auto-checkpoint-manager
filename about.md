# Auto-Checkpoint Interval Manager

Tired of forgetting to place checkpoints during long practice runs? This mod automatically drops a practice mode checkpoint for you at regular percentage intervals!

### Features
* Customize the interval gap anywhere from every **1%** to every **50%**.
* Safely avoids duplicating checkpoints on the same frame.
* Easily toggleable via the mod settings menu. 

*Created with the Geode SDK.*
